
## 📊CSVDataSheetComparer #
### Program that parses two CSV data files to compare and analyze attribute values with each other #

|IDE| Version |
|--------|-----|
|Visual Studio Community 2022| 17.4.3 |

|Language| Framework |
|--------|-----|
|C#| Windows Form (.NET6) |

#
## 📊Main screen
<img src="https://user-images.githubusercontent.com/75249093/209571341-d59d9dd2-7f61-4e06-a4e3-dbc12b11157f.png" width="600" height="400"/>

 * Search button : button to select two csv files to compare
 * Make Chart button : Enable when y-axis data properties of two imported csv files are selected, create chart
 
#
## 📊CSV loading screen
<img src="https://user-images.githubusercontent.com/75249093/210582093-e29fa59e-b98f-4efb-a1c9-5de734144714.png" width="800" height="400"/>

 * The file names of the two csv files imported to the top are printed.
 * Double-click the properties of the imported data sheet to set the y-axis data properties on the left.

#
## 📊Check parameter screen
<img src="https://user-images.githubusercontent.com/75249093/211336785-c789a83b-2c88-446d-953d-817f3c0b0f8c.png" width="600" height="400"/>

 * When the y-axis properties of both data sheets are selected and clicked while the Make Chart button is activated, the range of the x-axis (number of rows) and the range of the y-axis (value of column) are output.
 * In this case, when the Apply button is clicked, a graph is drawn based on the selected value.
